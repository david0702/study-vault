This is a **zero-dependency notes site**: write Markdown files, run one command, get a static site you can host anywhere. No framework, no build tooling — `index.html` is the entire application.

> [!note] Where to start
> Read the two example notes below. They link to each other, which is the whole point: **links, not folders, are the table of contents.**

## Example notes

- [[getting-started|Getting started]] — how to add, edit, and organise notes
- [[markdown-guide|Markdown guide]] — every syntax this site supports

## Conventions

| Convention | Why |
| --- | --- |
| One idea per note | Notes that argue two things get linked from nowhere |
| Links over folders | Folders are shelves; links are the argument |
| Filename = ID | `bayes-theorem.md` is linked as `[[bayes-theorem]]` |
